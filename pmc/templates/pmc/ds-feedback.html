Messages

Django messages appear fixed at the top of the viewport, out of the page flow. Success and info dismiss themselves after five seconds; warnings and errors wait to be dismissed. Messages from htmx responses arrive through the HX-Trigger header. Use the right level: messages.success, info, warning, error.

{% kc_example themed no_markup %} {% include 'pmc/_message.html' with level='success' text='Result recorded.' %} {% include 'pmc/_message.html' with level='error' text='That player is already on the ladder.' %} {% end_kc_example %}

Confirm

hx-confirm opens the confirm dialog. The question is shown as plain text, never HTML, so names and nicknames are safe to include.

Dialog

A native <dialog class="dialog">: a bottom sheet on phones, centred from 480px. Open with data-dialog-open="id", close with data-dialog-close, Escape or the backdrop. For content loaded by htmx, target #dialog; it opens when the response lands.
