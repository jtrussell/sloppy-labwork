Page header

The top of a page: optional back link, title with actions, and subheadings. It replaces the page's h1, so it carries the same top and bottom margins as an h1 in page flow (none inside a stack).

The page's main create action is a full-size .button-primary in .page-header__actions. Other actions on the thing the page is about go in an action menu.

Section header

A heading with actions for a section within a page. Stacks on phones. A create action for the section is a small secondary button (.button.button-small), so it never competes with the page's primary action.
