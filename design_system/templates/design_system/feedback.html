Notes

Short, page-level feedback. Django messages render as notes through components/messages.html.

{% ds_example themed %}
Registration closes at noon.
Pairings for round 2 are posted.
Lineup saved.
This deck is missing a house.
We couldn't save your changes.
{% end_ds_example %}

.note-danger is the original name of .note--danger; both render the same, prefer the new one.

Callouts

Longer guidance that sits within the page content, such as instructions for the current step.

{% ds_example themed %}

Step 2 of 5

Choose one deck for your opponent to ban.

Blocked

Waiting for your opponent to submit their lineup.

{% end_ds_example %}

Badges

Compact status labels. Badges take their border from the text color, so tones follow the theme. .badge--subtle is deliberately low-contrast; don't use it for information people need to read.

{% ds_example themed %}
Draft Standard Safe Pending Banned Stolen Ineligible Game Tinted {% include "components/icon.html" with name="eye" %} Public
{% end_ds_example %}

Loading

Pair .loading-text with htmx's .htmx-indicator class for request feedback, and use .skeleton blocks as placeholders for content that's on its way. Skeletons stop pulsing for people who prefer reduced motion.

Loading pairings…
{% end_ds_example %}
