Notes

Short, page-level feedback that sits within the page content.

Lineup saved.
This deck is missing a house.

.note-danger is the original name of .note--danger; both render the same, prefer the new one.

Messages

Django messages render through components/messages.html, which page.html and page-full.html already include. They float at the top of the viewport, above the page, so showing or dismissing one never moves the content. Load js/messages.js for the behaviour: every message has a dismiss button, success and info messages leave on their own after five seconds unless the pointer or keyboard focus is on them, and warnings and errors stay until dismissed.

Messages added during an htmx request arrive through the HX-Trigger header and stack below the ones already showing. Their text is escaped unless it is marked safe, so build links with format_html.

messages.success(request, 'Lineup saved.')

Badges

Compact status labels. Badges take their border from the text color, so tones follow the theme. .badge--subtle is deliberately low-contrast; don't use it for information people need to read.

Loading
