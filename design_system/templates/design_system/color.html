Tints

Tinted backgrounds are mixed from a semantic color and the --tint-subtle / --tint-strong percentages, never hard-coded. Contrast themes set both to 0%, so tinted elements fall back to their border and text color.

color: var(--color-danger);
background-color: color-mix(in srgb, currentColor var(--tint-subtle), transparent);
