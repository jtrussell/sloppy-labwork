Field

Render each Django form field with components/field.html. It outputs the label, required marker, help text, widget, then errors below the widget, and keeps Django's aria-describedby and aria-invalid wiring.

{% verbatim %}{% include "components/field.html" with field=form.deck_name %}{% endverbatim %}

Whole forms

For straightforward forms, components/form-fields.html renders non-field and hidden-field errors, hidden fields and every visible field in a .stack.stack--md. Follow it with .form-actions.

{% verbatim %}<form method="post">
  {% csrf_token %}
  {% include "components/form-fields.html" with form=form %}
  <div class="form-actions">
    <button type="submit" class="button button-primary">Save</button>
    <a href="…" class="button">Cancel</a>
  </div>
</form>{% endverbatim %}

Guidelines

  • Every input has a visible label. Placeholders are examples, not labels.
  • Put explanatory text in the form field's help_text so it's announced with the input.
  • Space fields with the stack gap; fields carry no margins.
  • Mark only required fields; don't mark optional ones.
